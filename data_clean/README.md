# Cleaned Data
 
This folder contains the cleaned and prepared student performance dataset used for analysis.
 
## File
 
- `students_performance_clean.csv` – Cleaned version of the original student performance dataset.
 
## Data Cleaning
 
The student performance dataset was reviewed and prepared for analysis by:
 
- Reviewing the number of rows and columns
- Reviewing column names and data types
- Checking for missing values
- Checking for duplicate rows
- Reviewing summary statistics
- Reviewing unique values in the categorical variables
- Checking the range of math, reading, and writing scores
- Checking for test scores outside the valid 0–100 range
- Checking categorical variables for extra whitespace
- Creating a copy of the dataset for preprocessing
- Verifying the cleaned dataset before saving
 
## Data Quality
 
The dataset contained no missing values or duplicate rows. The test scores were also checked to ensure they were within the valid 0–100 range.
 
## Purpose
 
The original dataset is preserved in the `data_raw` folder. The cleaned dataset in this folder is used for the analysis and visualizations completed in the student performance project.
