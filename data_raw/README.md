# Raw Data
 
This folder contains the original student performance dataset used for this project.
 
## Dataset
 
- `raw_students_performance_data.csv` – Original student performance dataset before data cleaning or preprocessing.
 
## Purpose
 
 The raw dataset is kept unchanged to preserve the original data. Any data cleaning, preparation, or transformations are performed separately, with the cleaned dataset stored in the `data_clean` folder.
