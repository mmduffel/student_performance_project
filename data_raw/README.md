# Raw Data
 
This folder contains the original student performance dataset used for this project.
 
## Dataset
 
- `raw_students_performance_data.csv` – Original student performance dataset before data cleaning or preprocessing.
 
## Purpose
 
The raw dataset is kept unchanged to preserve the original data. The dataset is loaded into Google Colab using Python and pandas for review and preprocessing.
 
Any data cleaning or preparation is performed separately, with the cleaned dataset saved in the `data_clean` folder.
