# Results
 
This folder contains the final outputs from the analysis of the student performance dataset.
 
## Files
 
- `student_performance_analyzed.csv` – Contains the final analyzed student performance dataset, including the overall average score created during the analysis.
 
- `MMD_ResultsFolders_Student Performance Dataset.pdf` – Contains the written answers and interpretations for the student performance data visualization questions.
 
## Data Visualizations
 
- `V1_gender_boxplots.png` – Compares math and reading scores by gender.
 
- `V2_test_prep_math.png` – Compares average math scores based on test preparation course completion.
 
- `V3_lunch_performance.png` – Compares mean overall student performance by lunch type.
 
- `V4_subject_correlations.png` – Shows the correlations among math, reading, and writing scores.
 
- `V5_math_reading_test_prep.png` – Shows the relationship between math and reading scores by test preparation course.
 
## Purpose
 
This folder contains the final analyzed dataset, written interpretations, and visualization outputs from the student performance analysis. The Python code used to generate the visualizations is located in the `src` folder.
